# Teste A/B - Página de produto (OfficeSupply Online)

Aluna: Martie Bello Silva — FATEC Cotia, DSM, Experiência do Usuário (P2, 2026/2).

- `index.html` — página de entrada com um card para cada versão; o clique abre direto o `index.html` da versão escolhida.
- `control/` — Versão A (controle), fornecida no enunciado (somente fechamento de tags e remoção de um `---` solto).
- `variant-b/` — Versão B (variante), com layout, HTML, CSS e JS próprios, incluindo telas de Início, Produtos, Promoções e Contato, menu responsivo, carrinho e checkout simulados (demonstração, sem envio de dados).

Os dados de avaliações, preços avulsos e prazos da variante são fictícios, criados para o exercício.

## Publicar no GitHub Pages
1. Suba esta pasta para um repositório no GitHub.
2. Settings > Pages > Source: branch `main`, pasta `/ (root)`.
3. URLs: `https://SEU-USUARIO.github.io/NOME-DO-REPO/control/` e `.../variant-b/`.
